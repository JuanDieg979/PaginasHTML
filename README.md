## 📂 Estructura del Proyecto
El repositorio está organizado de la siguiente manera para mantener el orden de los archivos:

* **`index.htm`**: Menú principal con tabla de navegación y enlaces directos.
* **`/programas/`**: Carpeta que contiene los 15 archivos `.htm` y el archivo de listas.
* **`/imagenes1/`**: Directorio de recursos visuales (fondos y patrones).

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructuración de las páginas y creación de tablas de navegación.
* **Diseño:** Uso de atributos de fondo (`background`), alineación y manejo de colores en tablas.
